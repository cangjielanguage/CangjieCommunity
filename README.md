# 社区介绍

**仓颉编程语言作为一款面向全场景应用开发的现代编程语言**，通过现代语言特性的集成、全方位的编译优化和运行时实现、以及开箱即用的 IDE 工具链支持，为开发者打造友好开发体验和卓越程序性能。
